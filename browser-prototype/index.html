What this prototype changes

  • Detection runs in JavaScript in your browser.
  • A non-exportable AES-GCM key is generated by the browser.
  • Matched values are encrypted and replaced with placeholders.
  • The backend receives only the sanitized prompt when you press Send.
  • The AI provider never receives the browser encryption key or vault.

Detection is limited to email addresses, phone-like strings and 10–12 digit identifiers. It can miss sensitive data or flag ordinary text.
